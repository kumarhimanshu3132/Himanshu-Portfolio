A modern, high-performance personal portfolio website built with clean semantic HTML5, modern CSS3 (Neo-Luxe Glassmorphism & custom CSS variables), and vanilla ES6+ JavaScript. Showcasing software engineering projects, full-stack web applications (MERN), interactive web games, academic foundations at Marwadi University, and verified credentials.

---

## ✨ Features

- **Neo-Luxe Glassmorphism UI:** Dark theme aesthetic with dynamic glowing mesh gradient background, ambient lighting, and subtle 3D card perspective tilt.
- **Scroll Reveal Animations:** Smooth glide-up and fade-in transitions powered by native `IntersectionObserver` with staggered cascades for project cards and skill groups.
- **Interactive Reading Progress Bar:** Dynamic top progress bar indicating document reading progress.
- **Dark / Light Mode:** Seamless theme toggle with local storage persistence.
- **Verified Featured Projects:**
  1. **Food Mania (MERN Full Stack):** End-to-end food ordering platform with React, Node.js, Express, MongoDB, and Context API.
  2. **React Snake Arcade:** Retro arcade game built with React featuring collision physics, score multipliers, and mobile touch D-Pad controls.
  3. **TechCrestaX Product Explorer:** Interactive TypeScript catalog explorer with instant search and dynamic filtering.
  4. **Weather Application:** Real-time atmospheric climate tracker integrated with OpenWeather API.
  5. **FreshMart Grocery Website:** Clean storefront e-commerce interface with DOM-driven cart interactions.
- **Academics & Certifications:** Comprehensive education milestones (9.04 CGPA at Marwadi University) and verified industry credentials (Tata GenAI, AWS Academy, Cisco CCNA, etc.).
- **Interactive Contact Form & Direct Channels:** AJAX-powered direct messaging via FormSubmit with automatic mailto fallback and 1-click clipboard copy for phone and email.

## 🚀 Getting Started

To run this portfolio locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kumarhimanshu3132/Himanshu-Portfolio.git
   cd Himanshu-Portfolio
   ```

2. **Open in browser:**
   Double click `index.html` or open it with your browser:
   ```bash
   start index.html
   ```
